# operating_agent

从已登录的小红书首页推荐中发现共创、合作、比赛和活动，按价值排序候选。网页只保留候选机会和素材库。

首次安装见 [部署与安装.md](部署与安装.md)。在两个终端分别启动（Mac 使用 python3）：

```text
python 启动界面.py
python 启动浏览器.py
```

打开 http://127.0.0.1:8765/ 。需要理解素材时以 `python 启动界面.py --ask-key` 启动，密钥不回显、不落盘。

先在 Playwright 专用 Chrome 中登录所需的小红书账号，利用该账号已有关注、收藏所形成的首页推荐。网页点击“开始探索”，选择新建或继续项目；名称可编辑，偏好方向与素材目录均可不填。选择目录后复用或完成Gemini理解再保存。复制提示词到本机 Codex。Codex 按 [search-opportunity](skills/search-opportunity/SKILL.md) 真实浏览、阅读、判断并逐批保存；网页显示进度，本身不是无人值守浏览后台。

Agent 刷新首页，点击相关原帖，保存好机会；对当前开放且有明确价值的原帖点赞收藏，已完成的不会重复点击。绝不关注作者。站内搜索、网页搜索、种子词和旧 Frontier 不再作为发现入口。遇验证码或登录失效由用户处理，不绕过。

评分项为流量扶持、现金激励、商业合作、曝光增长、用户偏好，默认权重30/25/20/15/10；新建或继续项目时可改，总和100。官方原文支持已知分数，未知不加分，过期单列；候选不代表所有报名条件均已确认。每个项目独立积累机会、浏览历史、可选偏好及素材。素材库显示当前项目，移除素材不会影响其他项目或原文件。探索不读取素材、不做素材匹配，只按用户偏好评估最后一项；偏好未填写不加分。

给同事查看时，选择项目后点击右上角“导出网页”，发送下载的 HTML 文件即可。双击离线查看卡片及折叠详情，原帖链接需联网；它是导出时快照，不自动更新。文件仅含当前项目的候选信息，不含素材、执行任务或本机配置。

文件记录：`data/homepage.json`；人工可读的 `data/首页探索记录.md`、`data/首页候选机会.csv`。素材库与理解缓存仍用 `workspace.json/materials.json`。删除素材包不删除原文件，探索不会重新调用 Gemini。

原始素材处理规则、依赖与启动参数见部署文档。独立发布准备仍可访问 /publish，按 [prepare-publication](skills/prepare-publication/SKILL.md) 操作。报名、发布、支付和联系另需确认。

旧自由探索实现保存在 `free_exploration` 分支。`main` 使用按项目管理的首页流程，不再记录官方作者。源码打包：`python 打包项目.py`，不含账号、密钥、素材和业务数据。
